# Desafio DIO – Relatório de Vendas

## Sobre o desafio

Este projeto foi desenvolvido como parte de um desafio proposto pela DIO.

O objetivo foi analisar relatórios de vendas e utilizar os dados apresentados
para construir uma nova visão do relatório, com foco em informações
geográficas.

## Desenvolvimento

Primeiramente, foram analisados dois relatórios:

- Relatório de vendas por produtos e segmentos;
- Relatório de vendas e lucro por países.

A partir dessas informações, foi desenvolvido um terceiro relatório,
utilizando mapas para apresentar visualmente a distribuição das vendas,
unidades vendidas e lucro por país.

## Relatório final

O relatório final apresenta:

- Distribuição de lucro por segmento;
- Vendas e unidades vendidas por país;
- Lucro por país;
- Visualização geográfica através de mapas.

Os mapas foram utilizados para facilitar a comparação entre os países
e tornar a análise dos dados mais visual.
